# Character footsteps

Source supplied by the user: `813622__securesubset__footsteps-stone-rock-concrete-cement.wav` (SecureSubset, recording 813622).

The six concrete WAV files are individual steps trimmed from that recording, converted from 24-bit to 16-bit mono PCM, with short edge fades and peak balancing. No synthesized footsteps or music are included.

Playback is attached to the shared player scene, so the team demo and School_System use the same sounds. Actual grounded movement sets cadence; sprinting is faster/louder and sneaking quieter. Idle, blocked movement, hiding, capture, and disabled player input stop playback. Existing Monster noise-event rules are unchanged.
